# Независимая техническая проверка Med Study

**Цель:** проверить готовность веб-платформы и Android-оболочки к распространению за пределами небольшой тестовой группы. Успех GitHub Actions **не заменяет** ручного ревью и тестирования на реальных устройствах.

## Код и архитектура

- [ ] Проверить структуру `app.js`, жизненный цикл страниц, очистку обработчиков, отображение ошибок, потенциальные неопределённые значения и обработку невалидных JSON.
- [ ] Провести ревью загружаемых `data/*.json`: уникальные ID предметов/разделов/тем/вопросов, статусы доступности, обратная совместимость.
- [ ] Убедиться, что глобальная навигация не привязана к ВНС и при будущем добавлении третьей темы не потребует правок десятков функций.
- [ ] Проверить XSS/DOM injection: сейчас данные выводятся через `textContent` и создание DOM-узлов; сохранить этот принцип при подключении внешних конспектов.
- [ ] Предложить границы между каталогом, тестовым движком, хранением прогресса и представлением (нынешний `app.js` монолитный).
- [ ] Проверить реальный приём ссылок внешних источников: HTTPS, `noopener noreferrer`, отсутствие открытых перенаправлений.

## Android, WebView и релиз

- [ ] Сверить настройки `WebView` с требованиями Android/OWASP: `WebViewAssetLoader`, только локальные ресурсы в WebView, отключённый `file://` и `content://`, отсутствие ненужных JavaScript-мостов.
- [ ] Проверить внешние Intent и обработку недоверенных схем/доменов.
- [ ] Выполнить smoke-test на Android с системными кнопками «назад / домой / недавние», жестовой навигацией, вырезом камеры и крупным системным шрифтом.
- [ ] Проверить возвращение кнопкой Android: работает ли переход внутри SPA и предсказуем ли выход из приложения.
- [ ] **Подготовить постоянную релизную подпись**, хранимую вне публичного репозитория, и проверить обновление без потери данных.
- [ ] Проверить работу APK офлайн и после обновления встроенного контента.
- [ ] Проверить загрузку контента и offline/cache обновление в Chrome Android и Safari iOS.

## Хранение, приватность, безопасность

- [ ] Прогресс хранится в `localStorage`. Он не синхронизируется, может пропасть после удаления APK/очистки браузера. Добавить экспорт/импорт, резервирование и миграцию формата данных до массового использования.
- [ ] Не добавлять сведения о пациентах, пароли, закрытые учебные материалы, токены или приватные данные в открытый GitHub Pages.
- [ ] Проанализировать CSP, заголовки безопасности, ограничения статического GitHub Pages, зависимости Gradle/Actions и их фиксацию версиями.
- [ ] Проверить доступность интерфейса: клавиатура, `aria-current`, диалог «Ещё», работа при 200% увеличении, доступный контраст и лейблы.
- [ ] Открыть DevTools/Android logcat, проверить ошибки, производительность, время холодного запуска и память в длинных конспектах.

## Учебная достоверность (отдельная проверка)

- [ ] Проверить содержимое темы с кафедральной программой и учебниками; технический программист **не заменяет медицинского редактора**.
- [ ] Проверить права на иллюстрации, виртуальные микропрепараты, 3D-модели и возможность их распространения.
- [ ] Указать источники и версии контента; краткий/расширенный «готов» только после сверки по контрольным вопросам.

## Фактически проверено автоматикой

- Статическая валидация структур JSON, SVG и JavaScript.
- Playwright: сценарии мобильных нажатий и Android WebView-origin, включая вложенную навигацию.
- Android debug APK собирается GitHub Actions.
- Сайт публикуется GitHub Pages.

**Не проверено автоматикой в полном объёме:** реальный iPhone Safari, ручной аудит безопасности, производительность на старых устройствах, сохранность прогресса при релизном обновлении, медицинская полнота курса.
