# Med Study 1.6 — контроль кафедральных видеокадров

**Источник:** семь MOV с исходными русскими именами, присланных владельцем 01.11.2026. Он разрешил разместить кафедральные материалы в открытой образовательной Med Study. Это основание для интеграции, но не означает экспертной верификации микроструктур.

**Техническое решение:** на каждое видео два **реальных отдельных кадра**, полученных без генеративной достройки, ретуширования тканей и вымышленной склейки. Исходные MOV сохраняются у владельца; на сайте достаточно доступных для увеличения JPG. В папке `photos/department/` остаются также 7 переданных оригинальных JPG, с названиями без изменений.

**Не делалось:**
- Не создавались «цельные» фотографии из несуществующих данных.
- Не подменялись исходные кафедральные названия.
- Не утверждались достоверные точечные координаты 1–3 на видеокадрах.
- Не удалялись исходные девять справочных микрофото Commons.
- Не объявлялся публикационный успех до загрузки бинарных JPG в GitHub.

## Сборка публичного сайта

Материалы подготавливаются пакетом `medstudy_kafedralnye_preparaty_1_6_assets.zip`: 7 JPG, 14 выбранных кадров, `data/department-public.json` и автономная HTML-версия для офлайн-подготовки. Все 21 медиафайлы проверены средствами Pillow по полному декодированию.

Для GitHub Pages нужно положить `photos/department/` из ZIP в публичную ветку подготовки (не менять регистр, пробелы и кириллицу), затем прогнать `scripts/validate_department_public.py`. Если хотя бы одно изображение отсутствует/повреждено, CI блокирует публикацию. Полная автоматическая передача бинарных вложений чата в GitHub не доступна в текущем подключении — **без загрузки этих файлов нельзя считать сайт обновлённым**.

### Учебный статус

Для каждого препарата ориентиры составлены как перечень, **что следует проверить**, а не как заявление, что на конкретном кадре видны все элементы. Подробные паспорта и проверенная пространственная разметка остаются отдельными задачами.
