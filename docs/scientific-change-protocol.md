# Med Study — протокол научных дополнений и журнал версий

**Редакция:** 2026-11-03. **Статус:** рабочее правило продукта, не медицинская экспертиза.
**Журнал, видимый в приложении:** [data/update-journal.json](../data/update-journal.json). **Сведения о правках ответов:** [data/gi-answer-reasons.json](../data/gi-answer-reasons.json).

## Два независимых потока изменений

1. **Функциональность / интерфейс** — релизы, навигация, тестирование, исправления, новые режимы, датированные ссылки на PR и результаты CI. Не представлять тесты GitHub как научную верификацию.
2. **Научное содержание** — добавленные, исправленные или уточнённые утверждения курса, привязанные к `chapterId`, конкретному утверждению и источникам. Не маскировать научную правку под технический релиз.

## После получения лекций

- Прочитать документ целиком и составить карту тем относительно действующих 17 глав, не заменяя существующую структуру курсом занятий.
- Отдельно фиксировать: **есть в курсе**, **действительно отсутствует**, **противоречит**, **лекция затрагивает поверхностно**, **ошибка распознавания/расшифровки — не подтверждена оригиналом**.
- Не удалять полезные сведения только потому, что преподаватель их не упомянул; не делать лекцию единственным эталоном.
- Проверять предлагаемые дополнения по надёжным учебным/научным источникам и по возможности по действующим кафедральным материалам; подлинные кафедральные изображения требуют отдельной визуальной проверки.
- **Не публиковать дословно чужие защищённые лекции, купленные конспекты или чужие фото.** Редакционный текст должен быть оригинальным и точно атрибутированным.
- Не менять ключи и ответы тестов без предметной проверки; отдельно фиксировать новые объяснения неправильных вариантов.
- Пока изменения только обсуждаются или не прошли проверку, не добавлять их как завершённые `scientificChanges`.

## Формат научной записи

В `data/update-journal.json` список `scientificChanges` состоит из записей:

```json
{
  "id": "sci-2026-11-XX-...",
  "date": "2026-11-XX",
  "version": "1.X.Y",
  "category": "science",
  "title": "Краткое название уточнения",
  "chapterId": "duodenum",
  "changes": ["Собственными словами, что было уточнено"],
  "verification": "Что сверено, кем/чем и что не проверено",
  "source": "https://github.com/Grobovchik797/med-study-platform/pull/XX"
}
```

**Обязательно:** доказательная запись в PR с указанием первичного фрагмента лекции (название и страницы/кадры; оригинал можно хранить только в безопасном месте), внешних ссылок и мотивировки изменения. Если отсутствует надёжный источник или нет права на публикацию — оставить в служебной карте проверки, не выдавая за новое научно подтверждённое содержание.

## Статус 1.9.3

- Пояснения к 24 неправильным вариантам итогового экзамена — **редакционный слой на основе существующего курса**, ещё не подтверждённый преподавателем. Не менять исходные тестовые ключи и тексты.
- Научные дополнения из лекций пока отсутствуют: файлы лекций ещё не предоставлены. Не заполнять журнал выдуманными правками.
- Веб-публикация, браузерный тест и Android debug-сборка — отдельные технические проверки по GitHub Actions.

## Проверка перед релизом

`python3 scripts/validate_study_tools.py` проверяет JSON и покрытие 24 итоговых вопросов; `tests/mobile-smoke.cjs` проверяет поиск, фильтры журнала и вывод пояснений. Технический успех этих проверок не доказывает медицинскую полноту.
