# Пищеварительная система · карта источников и контроль качества версии 1.0

**Статус: редакционный учебный черновик, а не полный утверждённый кафедральный учебник.**

## 1. Основание

- **Загруженная пользователем методичка**: *Методические разработки к практическим занятиям по гистологии, цитологии и эмбриологии*, Астраханская государственная медицинская академия, 1999, 130 PDF-страниц. Темы пищеварения: **PDF 96–110 (печатные стр. 97–111)**.
- **Предыдущая расшифровка пользователя** `Пищеварительная_система_по_порядку_органов.docx`: 219 абзацев (могут быть артефакты голосового ввода). **Никаких дословных 43-страничных копий в публичный репозиторий не загружено**. Содержание использовано как тематический ориентир наряду с методичкой.
- **Дополнения и внешняя проверка**: OpenStax *Anatomy & Physiology 2e*, глава 23; NCBI Bookshelf *Physiology, Gastrointestinal*. Исторические и новые сведения нельзя смешивать без уточнения источника.
- Эта методичка **не гарантирует соответствия текущим требованиям кафедры в 2026 году**; считать её учебной схемой, пока преподаватель не подтвердит актуальность.

## 3. Что создано в версии 1.0

- Каталог из **17 глав + существующий подробный модуль тонкой кишки + методические карты + итоговый тест**. У каждой главы есть вводная, краткая и расширенная подача. Глубина раскрытия на данном этапе различается; многие новые главы пока содержат **только базовый уровень и выбранные клеточные механизмы**.
- **56 контрольных вопросов**, перечисленных и связаны с главами: 9 по слизистой рта, языку и миндалинам, 15 по зубу и слюнным железам, 21 по пищеводу/желудку/кишечнику, 11 по печени/поджелудочной.
- **7 заполненных ориентировочных карт**: строение стенки; язык и миндалины; слюнные железы; ткани зуба; клетки желудка; клетки ворсинки и крипты; большие железы. Заполнения авторские, а не из книги ответов кафедры.
- **51 мини-тест** (по 3 в конце каждого подраздела), **24 отдельных итоговых теста** (8/8/8).
- Микрофотографии встраиваются **только рядом с относящимся к ним разделом**; в полном пилоте тонкой кишки удалён блок повторяющейся галереи.
- Из просмотра препарата появилась кнопка возврата к предыдущему разделу и месту прокрутки. В третьем режиме «Найди структуру» студент выбирает координату **подтверждённой крупной области**, а не отдельную клетку. Для jejunum без верифицированных маркеров этот тренажёр честно недоступен.

## 4. Чего пока не хватает

1. **Полной глубокой редакции каждой из 17 глав** (орган → оболочка → клетка → органелла → транспортные механизмы → регуляция/иммунология). Наличие переключателя «Расширенный» не означает законченную кафедральную глубину для всех глав.
2. **Иллюстрированного атласа каждого органа, высокого разрешения и экспертной разметки**; часть реальных снимков остаётся внешней и может не открываться на Android. GitHub issue #22 остаётся открытой.
3. Подробных схем зубного развития, крупных желез и микро-ультраструктуры, а также **желчного пузыря** отдельной главой.
4. Экспертной проверки 56 вопросов и корректности всех ответов по действующему учебному плану; особенно внимательно проверять ошибки голосовой расшифровки, спорные количественные величины и ретроспективные схемы 1999 года.
5. Полной синхронизации, сохранения навигации при закрытии приложения и нативной системной кнопки Android «назад»: сейчас в интерфейсе добавлена **собственная кнопка возврата к месту чтения**.

## 5. Правило развития

Научные расхождения с купленным материалом **сначала показывать владельцу** со страницей исходника и современным подтверждением. Правки исходного 43-страничного файла без согласования не делать. Не закрывать подготовку как «100% завершено», пока владелец не прошёл реальные тесты/препараты и не подтвердил полноту.
