Для каждого изображения заданы первоисточник, лицензия, автор, окраска (если была указана автором), диагностические ориентиры. При сборке изображение **уменьшается**, но анатомические детали не ретушируются, и сохраняется ссылка на авторский файл. Права на исходную микрофотографию определяются её собственной лицензией.

## Три режима и честная оценка

1. **Изучение** — фото, наименование, описание и только подтверждённые крупные метки.
2. **Самопроверка** — определить орган; если точные метки есть — проверить их подписи.
3. **Найди структуру** — по проверенным координатам автоматическая приблизительная проверка; для шести новых препаратов — самостоятельный поиск с подсказкой **без машинной проверки точки и без баллов**.

Один фундальный срез используется в двух родственных главах («желудок» и «железы желудка») с прямым указанием, что это именно фундальный отдел. Подмена органов недопустима.

## Не закрыто в 1.4

- Ещё нет самостоятельных проверенных микрофотографий для общего плана (сравнение нескольких органов вместо одного среза), слизистой губы/щёки/нёба, языка, вкусовых почек, миндалины, зуба и глотки.
- Нет научно подтверждённых координат отдельных клеток для шести новых фото.
- Библиотека не является электронным кафедральным атласом с экспертным заключением; снимки могут отличаться от реальных препаратов кафедры окраской, увеличением и качеством.
- На реальном телефоне пользователь должен оценить читаемость новых снимков; успешная сборка сама по себе не означает научную экспертизу.
