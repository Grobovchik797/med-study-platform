# План Med Study: ближайшие обновления после 1.1

**Зафиксировано:** 1 ноября 2026 по замечаниям владельца; сверено с исходным кодом ветки `main`.  
**Это план, не утверждение о выпущенных функциях.** Значимые изменения в коде — отдельными PR и проверками.

## 1.2 — устранить ошибки маршрутов и смешение предметов

Приоритет — правильная работа **уже добавленных** глав и тестов; не заявлять кафедральную завершённость.

1. **Атлас ЖКТ** — [Issue #28](../issues/28): клик по двенадцатиперстной, тощей и подвздошной кишке должен открывать препарат нужного отдела, а не `data/atlas.json` рецепторов ВНС. Если препарата нет — явное сообщение, не подстановка чужого. Сохранить возврат из препарата к чтению. Отдельно протестировать на Android.
2. **Статистика** — [Issue #29](../issues/29), [#17](../issues/17): в статистике глав ЖКТ не выводить «медиаторы / рецепторы / эффекторные органы» из банка ВНС. Разделить статистику по предметам и темам, не удаляя существующий прогресс. Если конкретный вопрос не учитывается, честно объяснить это пользователю.
3. **Тематические тесты** — [Issue #30](../issues/30): существующие 3 мини-вопроса у каждой главы оставить; кнопка «Тест по этой теме» запускает только задания связанной главы, общий итоговый экзамен ЖКТ остаётся отдельным пунктом. Доступных заданий может быть мало; показывать реальное количество и не обещать уровни/объём, которые не реализованы.
4. **Регрессия**: тесты переходов, возврат к чтению, отсутствие чужих данных, сохранение старого localStorage, проверка мобильного поведения. До ручной проверки на устройствах не считать релиз полностью подтверждённым.

### Почему 1.2 именно такая

По текущему `app.js`:
- `showResourceLibrary('atlas')` для всех атласных тем, кроме пилота тонкой кишки, вызывает `navigate('atlas')`, который открывает атлас ВНС.
- `showStats()` обрабатывает отдельно только `histology-small-intestine`, а остальные темы с `quiz:true` получают `questionBank.questions` и категории ВНС.
- `showGIChapter()` передаёт в `gi-course.js` `onExam:showGIExam`, то есть общекурсовый тест; в `gi-course.js` три мини-теста на главу уже существуют.

## 1.3 — кафедральные ориентировочные карты

[Issue #31](../issues/31), связь с [#26](../issues/26). После предоставления владельцем оригинального PDF/сканов **сохранить точный набор карт**, заголовки, столбцы, строки, их порядок, объединения и формулировки, а не авторскую форму «по смыслу». Заполнение — отдельно с источником/проверкой; научные несоответствия не менять скрытно, а согласовывать. На мобильном сохранять табличную структуру, допуская прокрутку/адаптацию без потери ячеек.

**До получения оригинала** нынешние `data/gi-workbook.json` (7 авторских реконструкций) нельзя объявлять точным кафедральным образцом. Для независимой проверки нужна постраничная сверка с оригиналом.

## 1.4 — реальный атлас каждого органа, три режима

[#14](../issues/14), [#22](../issues/22), [#26](../issues/26). Получить файл с препаратами от владельца. Каждое изображение оценить по: органу/отделу, окраске, видимым структурам, разрешению, достоверности подписей, праву использования и источнику. Только после подтверждения — включать в главу. Три пользовательских режима: **изучение**, **самопроверка**, **«Найди структуру»**. Где уверенной пространственной разметки нет — не изображать её существующей. Обязательная проверка загрузки на Android.

## 1.5 — закрепление знаний по каждой теме

Тематические банки достаточного объёма, три уровня сложности после проверки по источникам, карточки самовоспроизведения, разбор ошибок и статистика прогресса. Учебный цикл «30 минут работы + 5 минут перерыв» — опция, а не обязательный режим и не заявление о доказанно идеальном времени. Расширять таймер на другие главы, если владелец подтвердит удобство.

## Научные и продуктовые границы

- **17 глав и 85 дополнительных блоков** по версии 1.1 не являются гарантией завершённой научной редакции.
- Работа над ошибками с возвратом в конспект — удачную существующую функцию следует сохранить.
- Контрольные вопросы методички остаются привязанными к главам; карты из методички не подменяют её оригинальные таблицы.
- Не создавать фальшивые препараты и не объявлять общие вопросы тематическими.
- Отдельный общий итоговый тест пищеварительной системы сохраняется как самостоятельный режим.
- Обновления должны быть небольшими, проверяемыми и иметь конкретный список изменений.
- Перед выпуском считать нужными проверки GitHub Actions, локальные/мобильные тесты и просмотр владельцем.
