# Med Study — версия 1.1: подробная гистология, локальные микропрепараты

**Сайт (одна постоянная ссылка):** https://grobovchik797.github.io/med-study-platform/


## 1.1 · Углубление и исправление загрузки микрофотографий

- Во всех 17 главах теперь **только два режима** — **краткий** и **расширенный**. Вводный не показывается; прежний материал тонкой кишки в архиве данных сохранён для совместимости.
- Добавлено **85 новых авторских тематических блоков** (по 5 на каждую из 17 глав), в том числе клеточные и ультраструктурные механизмы, функции, сравнения и диагностические признаки. Краткий формат содержит основные выводы из каждого блока; расширенный — подробное объяснение.
- **85 новых интерактивных вопросов непосредственно после тематических блоков**, плюс прежние 51 мини-вопрос после глав и 24 итоговых вопроса (всего 160 проверочных заданий в новых GI главах без учёта старого пилота тонкой кишки).
- **Три реально лицензированные микрофотографии тонкой кишки** скачиваются и проверяются на этапе сборки и включаются в сайт, PWA-кеш и Android APK. Браузер больше не загружает их напрямую с Wikimedia и не отправляет изображение в сторонний прокси. Если загрузка при сборке не удалась, сборка завершается с ошибкой, а не публикует пустую галерею.
- Авторы и лицензии CC BY-SA 4.0 сохранены, изменение размера без ретуши отмечено. **Микропрепараты остальных органов пока не добавлены**, нельзя выдавать иллюстрации SVG за настоящие гистологические срезы.
- Учебные разделы **по-прежнему требуют научной редакционной проверки**: расширенность текста не равна подтверждению официальной кафедрой. Список нерешённых задач — `docs/gi-source-crosswalk.md`.

## 1.0 · Учебный курс по кафедральной методичке

**Главный раздел:** Мои предметы → Гистология, цитология → Пищеварительная система.

- **17 учебных глав** от общего плана стенки, ротовой полости и языка до желудка, кишки, печени и поджелудочной железы. Отдельно сохраняется прежний подробный пилот «Тонкая кишка» с 30 тестами.
- В версии 1.0 у глав было три формата; в 1.1 вводный убран, оставлены краткий и расширенный. **Пока это базовая учебная редакция; полная экспертная глубина всех глав ещё не завершена.** Научные правки купленного оригинала не вносились.
- **3 новых вопроса в каждом разделе** (всего 51), ответы и пояснения открываются на месте; **24 отдельных итоговых вопроса** по трём сложностям, не дублирующих мини-тесты.
- **56 контрольных вопросов** из методички Астраханской ГМА (1999), связаны с соответствующими главами. Это исторический источник, не утверждённый актуальный экзаменационный регламент 2026 года.
- **7 заполненных ориентировочных карт**: общая стенка, язык/миндалина, слюнные железы, зуб, клетки желудочных желёз, ворсинки/крипты, печень/поджелудочная. Ответы — авторская редакция.
- Препараты в подробном пилоте тонкой кишки перенесены к относящимся к ним объяснениям, **нет одинаковой общей галереи в каждом конспекте**. Из препарата есть кнопка возврата к предыдущему разделу и месту чтения.
- Третий режим **«Найди структуру»**: по одному последовательно ищет достоверно размеченные крупные области. Неизученный jejunum без подтверждённых меток не получает фиктивных координат. Загрузки внешних снимков всё ещё зависят от доступности Wikimedia и требуют следующей работы.
- [Редакционная карта двух источников, источники и нерешённые вопросы](docs/gi-source-crosswalk.md).

## Med Study 0.9 — наглядные конспекты и режим фокуса

В модуле **Гистология → Пищеварительная система → Тонкая кишка** без изменения научных утверждений реализованы:

- Вводный, краткий **и расширенный** форматы теперь содержат схему ворсинки/крипты и мини-галерею реальных микропрепаратов. Подписи ведут в интерактивный микроскоп.
- В конспектах смысловое оформление терминов, **NB / Nota Bene**, пояснения в скобках с отдельным цветовым стилем; медицинские формулировки и исходный купленный файл не переписаны.
- Настраиваемый в перспективе, пока фиксированный **добровольный** учебный цикл 30 мин + 5 мин: этапы подготовки, предварительной карты, чтения, микроскопии, воспроизведения, тестов и перерыва. Таймер можно поставить на паузу/сбросить; при смене экрана он останавливается и не обещает освоение всего курса за одну сессию.
- Виртуальные препараты теперь используют более компактные миниатюры Wikimedia (на телефоне им всё ещё требуется интернет). Добавлен понятный статус загрузки, сообщение об ошибке и ручная повторная попытка через альтернативный канал изображения.
- **Ограничение:** GitHub Actions при попытке надёжно сделать локальные копии получил HTTP 429 от Wikimedia; даже промежуточный прокси не дал стабильного результата. Поэтому мы не заявляем офлайн-доступность микрофотографий и не выдаём проблему #22 за решённую. Экспериментальный `scripts/build_histology_images.py` оставлен как наработка, но не участвует в выпуске.
- Авторство и условия CC BY-SA 4.0 сохранены, изображения показываются по ссылкам на исходные ресурсы Wikimedia.
- **Научные предложения в журнале пока не утверждены пользователем**: данный релиз не содержит новых редакционных фактических исправлений.
- Ограничения: микроскоп по-прежнему использует обычные отдельные фотографии, не полнослайдовые WSI; клеточная разметка требует отдельной экспертной верификации на каждом снимке. Нет доказательства усвоения материала только от оформления/таймера.

## Med Study 0.8 — тонкая кишка по конспекту пользователя (пилот)

Этот этап основан на предоставленном пользователем **43-страничном платном конспекте пищеварительной системы**. Купленный исходник **не публикуется** в репозитории и не дублируется дословно. Публичные учебные объяснения и 30 тестовых вопросов написаны заново. Привязка к исходным страницам, список предлагаемых исправлений, ссылки на проверенные внешние источники находятся в [журнале редакционной сверки](docs/small-intestine-source-audit.md). Это **не утверждённая кафедрой** редакция.

Реализовано в «Мои предметы → Гистология, цитология → Пищеварительная система → Тонкая кишка»:

- 3 вида материала: вводный, краткий и расширенный. В них добавлены перекрёстные связи из общего плана ЖКТ, регуляции панкреатической секреции, сравнений толстой кишки и энтерогепатической циркуляции.
- **30 оригинальных вопросов**: 10 лёгких, 10 средних, 10 сложных; объяснение и ссылка на исходные страницы / внешнюю сверку у каждого; отдельное хранение статистики и ошибок по тонкой кишке (не смешиваются с ВНС).
- **3 лицензированные реальные гистологические фотографии**: дуоденум, jejunum и ileum с иммунным агрегатом. Режимы **«Изучение»** (показ подтверждённых меток) и **«Самопроверка»** (определение препарата и подпись областей); мобильный zoom, перемещение, атрибуция авторов и лицензии CC BY-SA 4.0.
- **Качество изображений:** при недостаточной уверенности в точной координате клетки/структуры метку намеренно не добавляем. На изображении jejunum сейчас только определение препарата без подписей; для duodenum и ileum метки обозначают крупные области. Заполнять их догадками нельзя.
- Изображения **загружаются с Wikimedia Commons через интернет** и могут не открыться офлайн, хотя конспекты и вопросы встроены/кэшируются. Ссылка на файл-источник видна всегда.
- Прогресс в `localStorage`, отдельно от старого ВНС; без синхронизации устройств. Имеющиеся тестовые Android APK могут конфликтовать по debug-подписи; не удалять старую установку с важными данными без сохранения.

**Дальше:** кафедральные вопросы, экспертная проверка подписей для 10–20 микроструктур на высококачественных срезах, локальная доступность изображений и безопасная миграция прогресса.

## Med Study 0.7 — навигация без привязки к ВНС

Структура каталога теперь **предмет → раздел → тема → доступные материалы**. Дерево `data/library.json` — источник данных о разделах и возможностях. Гистология уже организована по разделам (цитология, эмбриология, пищеварительная, дыхательная, сердечно-сосудистая, нервная системы, кроветворные и иммунные органы и т. д.); пилот «Тонкая кишка» относится к пищеварительной системе. В нормальной физиологии ВНС находится в разделе «Нервная система».

- Главная: общий обзор всех доступных тем; кнопка больше не отправляет автоматически на ВНС.
- «Мои предметы»: 11 дисциплин, затем разделы и темы; пустые разделы честно обозначены как запланированные.
- «Конспекты», «Атласы», «Карточки»: общие библиотеки материалов, привязанные к темам. Текущие реально доступные материалы не изменились.
- «Работа над ошибками» и «Статистика»: сгруппированы по реально доступным тематическим банкам, а не выглядят как универсальный глобальный банк ВНС.
- Внутри темы расположены только реально доступные действия: 3 конспекта тонкой кишки без вымышленных тестов и атласа, либо вводная ВНС с 20 тестами, атласом и карточками.
- Автоматические тесты проходят полный путь через каталог в мобильном браузере и симулированном Android WebView.
- Подразделы других дисциплин и новые банки тестов будут добавляться только при наличии проверенного контента.

### Что осталось архитектурно

Текущий тестовый движок работает с **одним банком ВНС**. Главная навигация и формат каталога уже универсальные, но полноценное подключение множества банков вопросов, миграция статистики и повторение ошибок между ними — отдельный следующий этап, требующий ID предмета/темы у каждого вопроса. Не заявлять, что все эти функции уже готовы для 11 предметов.

## Med Study 0.6.0 — библиотека учебных дисциплин и два формата

- В `data/subjects.json` зарегистрированы **11 дисциплин** университета. Предметы видны в разделе **«Мои предметы»** даже без готовых учебных материалов — такие карточки честно помечаются как «планируется».
- Для каждой темы предусмотрены **два вида конспекта**: **краткий** (вся необходимая база, основные механизмы и контрольные вопросы) и **расширенный** (орган → ткань → клетка → органеллы/биохимические процессы, с функциональными и иммунологическими связями по необходимости).
- Принцип объяснения **интегрированный**: при разборе желудка мы последовательно рассматриваем оболочки, железы, клетки, механизмы секреции и регуляцию; не дробим материал насильно на «пять дисциплин».
- Текущий конспект ВНС обозначен **вводным** — его ещё нельзя честно считать законченным кратким или расширенным материалом для кафедры.
- Обновлён стандарт `docs/integrated-medical-content-standard.md`, где приведены пример планирования темы «желудок» и требования к проверке полноты.
- Сайт и тестовый Android APK получают одну и ту же библиотеку предметов. **Наличие каталога не означает готовность учебного контента по всем дисциплинам.**

## Med Study 0.5.2 — навигация перенесена наверх

На телефонах **больше нет фиксированной нижней панели**: меню «Обзор / Предметы / Конспект / Ещё» находится сразу под верхней шапкой. Панель «Ещё» раскрывается сверху, а её кнопки доступны без взаимодействия с Android-кнопками «назад / домой / недавние приложения».

Причина исправления: реальные устройства Android с трёхкнопочной системной навигацией перекрывали нижнюю часть фиксированной веб-панели. Размещение выше решает геометрическую проблему вместо бесконечных исправлений отступов.

Автоматический мобильный тест дополнен проверкой координат и доступности меню на верхнем крае, с резервом для системных кнопок внизу. Это проверка в Chromium, а **установку на реальном Android по-прежнему должен проверить пользователь**.

### Тестовый APK устанавливается отдельно от предыдущего

Для безопасности следующая отладочная сборка получает Android package `io.github.grobovchik797.medstudy.preview` и название **Med Study (тест)**. Её можно установить рядом с предыдущей сборкой, **не удаляя прежнее приложение и не рискуя потерять в нём локальный прогресс**. Результаты в двух приложениях не синхронизируются. Поскольку отладочная подпись непостоянна, следующие отладочные APK сами по себе не являются безопасным механизмом обновлений; для них нужен полноценный релизный ключ и импорт/экспорт данных.

**Текущий APK всё ещё отладочный.** GitHub Actions создаёт новую подпись для каждой временной сборки; Android может не дать установить 0.5.1 поверх 0.5 без удаления старого приложения. **Удаление прежнего APK удалит сохранённый локальный прогресс.** Пока нет стабильного релизного ключа или реализованного экспорта результатов, не удаляй приложение с важными данными. Веб-сайт 0.5.1 обновляется по старой ссылке отдельно от APK.

## Med Study 0.5 — интерактивный атлас и Android APK

### Интерактивный атлас

В новой вкладке «Атлас» можно выбрать α1, β1, β2, β3, M2 или M3 и увидеть медиатор, орган, механизм, короткую подсказку и ссылку на NCBI Bookshelf. Данные расположены в `data/atlas.json` и доступны как в веб-версии, так и во встроенной Android-сборке.

### Настоящая Android-сборка для испытаний

`android/` — отдельный проект Android (Java + WebView + WebViewAssetLoader). Он содержит встроенную копию Med Study, загружаемую локально с безопасного специального адреса. Поэтому приложение имеет собственную иконку и собственное окно, а конспект, атлас и тесты доступны без интернета после установки. Внешние источники NCBI открываются системным браузером при наличии интернета.

Workflow `.github/workflows/android-apk.yml` собирает **отладочный APK** и сохраняет его в разделе *Artifacts* GitHub Actions на 14 дней.

1. Открой [GitHub Actions](https://github.com/Grobovchik797/med-study-platform/actions/workflows/android-apk.yml).
2. Выбери успешный запуск **Build Android APK (test version)**.
3. Внизу запуска открой *Artifacts* и скачай `med-study-android-debug-apk`.
4. Распакуй ZIP: внутри `app-debug.apk`, передай APK на свой Android и установи после проверки источника.
5. **Не выкладывай этот тестовый APK как релиз для широкой публики.** Отладочная подпись создаётся автоматически; между запусками она может отличаться. Поэтому новая отладочная сборка может не устанавливаться поверх предыдущей. Чтобы устанавливать стабильные обновления без удаления данных, нужна постоянная безопасно хранимая релизная подпись.

APK — отдельная копия сайта: в ней учебные файлы встроены и **не обновляются автоматически при публикации GitHub Pages**. Обновления сайта по прежней ссылке продолжаются; обновления APK требуют новой сборки и установки. Для App Store и Google Play понадобятся отдельные этапы подготовки и публикации.

### iPhone

Рекомендуемый способ без App Store: открыть сайт в **Safari** → меню «Поделиться» → «На экран Домой» → включить «Открывать как веб-приложение» при наличии переключателя → «Добавить». ```

Открой http://localhost:8000 — сайт загружает два файла JSON, поэтому прямое открытие `index.html` как файла может работать некорректно.

## Автоматизация

```bash
python3 scripts/validate_questions.py
node --check app.js\nnode --check sw.js\npython3 scripts/generate_icons.py\npython3 scripts/validate_pwa.py\npython3 scripts/validate_illustrations.py
```

GitHub Actions запускает обе проверки на Pull Request и при обновлении `main`; после успешного `push` в `main` публикует сайт на GitHub Pages. Публикация должна быть настроена в Settings → Pages → Source: GitHub Actions.

## Приватность

Сайт публичный, но не имеет регистрации. История ошибок и результаты хранятся **только в localStorage конкретного браузера**. После очистки браузера данные пропадут. Данные студентов не отправляются в удалённую базу и синхронизация устройств не настроена. Не размещай сюда сведения о пациентах, пароли или непубличные материалы.

## Важно о синхронизации прогресса

Результаты хранятся в **конкретном браузере или установленном приложении**, а не в GitHub. Телефон и компьютер не делятся прогрессом автоматически. Даже браузер и установленная версия PWA на одном телефоне могут хранить данные отдельно. Очищая данные приложения, можно потерять результаты. При изменении темы или очистке браузера часть статистики может перестать отражать текущий набор вопросов.
