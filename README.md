# Med Study — учебная платформа (0.2)

**Сайт:** https://grobovchik797.github.io/med-study-platform/

Адаптивная образовательная платформа для студентов медицинского вуза. Первая тема — **нормальная физиология: вегетативная нервная система**. Цветовое оформление: белый фон, фиолетовые акценты.

## Что доступно

- **Конспект по ВНС:** 5 тематических разделов с объяснениями механизмов, примерами, выводами и ссылками на NCBI Bookshelf.
- **20 вопросов с четырьмя вариантами ответа:** комментарий к правильному ответу и источник у каждого вопроса.
- **Быстрая тренировка:** 10 случайных вопросов из банка.
- **Работа над ошибками:** неверные ответы сохраняются в списке повторения и удаляются после верного ответа.
- **Статистика:** число завершённых тренировок и лучший результат (сохраняются локально в браузере).
- **Учебный план:** ориентировочный 30-минутный блок с активным воспроизведением.

## Проверенные справочные источники

Материал составлен с использованием открытых медицинских справочников NCBI Bookshelf:

- [Anatomy, Autonomic Nervous System](https://www.ncbi.nlm.nih.gov/books/NBK539845/)
- [Physiology, Autonomic Nervous System](https://www.ncbi.nlm.nih.gov/books/NBK538516/)
- [Autonomic Pharmacology](https://www.ncbi.nlm.nih.gov/books/NBK538180/)
- [Physiology, Muscarinic Receptor](https://www.ncbi.nlm.nih.gov/books/NBK555909/)
- [Physiology, Bladder](https://www.ncbi.nlm.nih.gov/books/NBK538533/)
- [Physiology, Acetylcholine](https://www.ncbi.nlm.nih.gov/books/NBK557825/)

**Ограничение:** это авторский учебный набор для самопроверки, а не официальный банк тестов кафедры. Автоматическая проверка GitHub Actions подтверждает структуру файлов и синтаксис JavaScript, но не заменяет преподавательскую рецензию, научную сверку терминов с конкретным учебником и тестирование в реальных браузерах.

## Структура

```text
index.html                   Главная страница
styles.css                   Оформление
app.js                       Навигация, тестирование, статистика
data/questions.json          20 вопросов и ответы
data/lesson.json             5 разделов конспекта
scripts/validate_questions.py Проверка данных
.github/workflows/deploy.yml Проверка и публикация GitHub Pages
```

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открой http://localhost:8000 — сайт загружает два файла JSON, поэтому прямое открытие `index.html` как файла может работать некорректно.

## Автоматизация

```bash
python3 scripts/validate_questions.py
node --check app.js
```

GitHub Actions запускает обе проверки на Pull Request и при обновлении `main`; после успешного `push` в `main` публикует сайт на GitHub Pages. Публикация должна быть настроена в Settings → Pages → Source: GitHub Actions.

## Приватность

Сайт публичный, но не имеет регистрации. История ошибок и результаты хранятся **только в localStorage конкретного браузера**. После очистки браузера данные пропадут. Данные студентов не отправляются в удалённую базу и синхронизация устройств не настроена. Не размещай сюда сведения о пациентах, пароли или непубличные материалы.
