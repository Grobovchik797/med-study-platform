# Med Study — первая учебная платформа

Статический сайт с демонстрационным модулем по нормальной физиологии. Оформление: белый фон, аккуратный фиолетовый интерфейс, адаптация под смартфон.

## Возможности

- Переходы «Обзор», «Мои предметы», «Работа над ошибками».
- Вопросы с четырьмя вариантами ответа, мгновенным объяснением и подсчётом баллов.
- Локальное сохранение количества пройденных тренировок, лучшего результата и списка ошибок через `localStorage`.
- Повторение ошибочных вопросов, при верном ответе они убираются из списка.
- Никаких аккаунтов, внешних API и отправки результатов на сервер.

## Важно о содержании

В `data/questions.json` пока **только пять демонстрационных вопросов** по вегетативной нервной системе. Они созданы для проверки логики интерфейса и не считаются экспертно утверждённым банком. Перед использованием для экзамена нужна сверка формулировок, ответов и источников с согласованным учебником.

## Запуск на компьютере

Нужен Python 3. Откройте терминал в папке проекта:

```bash
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000). Двойной щелчок по `index.html` может не сработать из-за ограничений браузера при чтении JSON.

## Публикация на GitHub Pages

1. Создайте **новый публичный репозиторий** `med-study-platform`. Не делайте публичным приватный `project-hub`.
2. Загрузите в корень нового репозитория файлы этого проекта, включая `.github/workflows/deploy.yml`.
3. В репозитории откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Откройте **Actions** и проверьте запуск `Validate and publish Med Study` после `push` в `main`. Если workflow появился до настройки Pages, его можно перезапустить.
5. Откройте выданный GitHub Pages URL. Для такого имени репозитория стандартный URL обычно имеет вид `https://Grobovchik797.github.io/med-study-platform/`, но наличие сайта подтверждается успешным развёртыванием, а не предполагаемым адресом.

GitHub Pages публикует сайт в интернете для всех, у кого есть ссылка. В репозитории не должно быть персональных медицинских данных, паролей или защищённых учебных материалов без разрешения.

## Качество и автоматизация

```bash
python3 scripts/validate_questions.py
node --check app.js
```

Проверка формата JSON и синтаксиса JS запускается автоматически через GitHub Actions на Pull Requests и при обновлении `main`. Проверка формата **не проверяет научную достоверность** вопросов.

## Приватность

Результаты сохраняются только в `localStorage` данного браузера и устройства. При очистке данных сайта прогресс исчезнет. В приватном режиме может не сохраняться. Сайт не предназначен для хранения данных пациентов.
