# Med Study — учебная платформа (0.3)

**Сайт (одна постоянная ссылка):** https://grobovchik797.github.io/med-study-platform/

## Установка на телефон (PWA)

1. Открой сайт по той же ссылке на Android или iPhone.
2. **Android / Chrome:** меню ⋮ → «Установить приложение» или «Добавить на главный экран».
3. **iPhone / Safari:** «Поделиться» → «На экран Домой» → «Добавить».
4. На поддерживаемых устройствах Med Study открывается отдельным окном по своей иконке. В иных браузерах это может быть ярлык на обычный сайт.

Сайт по-прежнему доступен из любого браузера. Обновления появляются по прежнему адресу после успешной публикации. При обновлении установленного приложения может понадобиться повторно открыть или перезагрузить его.

**Офлайн:** после первого успешного онлайн-открытия и кэширования базовые учебные материалы и тесты могут работать без интернета. Без первой загрузки автономная работа не гарантируется; очистка данных сайта удалит кэш. Для установки не нужно скачивать APK или IPA.

Адаптивная образовательная платформа для студентов медицинского вуза. Первая тема — **нормальная физиология: вегетативная нервная система**. Цветовое оформление: белый фон, фиолетовые акценты.

## Что доступно

- **Конспект по ВНС:** 5 тематических разделов с объяснениями механизмов, примерами, выводами и ссылками на NCBI Bookshelf.
- **20 вопросов с четырьмя вариантами ответа:** комментарий к правильному ответу и источник у каждого вопроса.
- **Быстрая тренировка:** 10 случайных вопросов из банка.
- **Карточки:** определения и пояснения из конспекта с возможностью раскрыть ответ и перемешать порядок.
- **Экзамен:** 20 вопросов без подсказок и показа правильных ответов до завершения, затем разбор ошибок.
- **Статистика разделов:** локальный подсчёт правильных ответов и попыток по четырём категориям.
- **Работа над ошибками:** неверные ответы сохраняются в списке повторения и удаляются после верного ответа.
- **Статистика:** число завершённых тренировок, лучший результат и результаты по разделам (хранятся локально в браузере).
- **Учебный план:** ориентировочный 30-минутный блок с активным воспроизведением.

Автоматическая проверка GitHub Actions подтверждает структуру файлов и синтаксис JavaScript, но не заменяет преподавательскую рецензию, научную сверку терминов с конкретным учебником и тестирование в реальных браузерах.

## Структура

```text
index.html                   Главная страница
styles.css                   Оформление\nmanifest.webmanifest         Описание установки и иконок\nsw.js                       Офлайн-кэш и обновление
app.js                       Навигация, тестирование, статистика
data/questions.json          20 вопросов и ответы
data/lesson.json             5 разделов конспекта
scripts/validate_questions.py Проверка данных\nscripts/generate_icons.py     Создание иконок 192/512 PNG\nscripts/validate_pwa.py      Проверка установочных файлов
.github/workflows/deploy.yml Проверка и публикация GitHub Pages
```

## Локальный запуск

```bash
python3 -m http.server 8000
```

Открой http://localhost:8000 — сайт загружает два файла JSON, поэтому прямое открытие `index.html` как файла может работать некорректно.

## Автоматизация

```bash
python3 scripts/validate_questions.py
node --check app.js\nnode --check sw.js\npython3 scripts/generate_icons.py\npython3 scripts/validate_pwa.py
```

GitHub Actions запускает обе проверки на Pull Request и при обновлении `main`; после успешного `push` в `main` публикует сайт на GitHub Pages. Публикация должна быть настроена в Settings → Pages → Source: GitHub Actions.

## Приватность

Сайт публичный, но не имеет регистрации. История ошибок и результаты хранятся **только в localStorage конкретного браузера**. После очистки браузера данные пропадут. Данные студентов не отправляются в удалённую базу и синхронизация устройств не настроена. Не размещай сюда сведения о пациентах, пароли или непубличные материалы.

## Важно о синхронизации прогресса

Результаты хранятся в **конкретном браузере или установленном приложении**, а не в GitHub. Телефон и компьютер не делятся прогрессом автоматически. Даже браузер и установленная версия PWA на одном телефоне могут хранить данные отдельно. Очищая данные приложения, можно потерять результаты. При изменении темы или очистке браузера часть статистики может перестать отражать текущий набор вопросов.
